# Sahayta Backend — FastAPI (Wave 2, Agent 5)

Implements `docs/api-contracts.md` v1.3 (FROZEN — additive changes only, see
`MIGRATION.md`). Modular monolith: one
FastAPI process, async SQLAlchemy 2.0, SQLite by default (Postgres via
`SAHAYTA_DATABASE_URL`), in-process WS event hub.

## Quickstart (5 minutes)

```bash
cd backend

# 1. virtualenv + pinned deps
python -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2. database — pick ONE:
.venv/bin/python seed.py --fresh        # drop + recreate + load all demo data
# or: .venv/bin/alembic upgrade head    # schema only (no data), for prod-like setups

# 3. run
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 4. verify
curl http://127.0.0.1:8000/api/health
# docs: http://127.0.0.1:8000/docs
```

No API keys are needed: with `SAHAYTA_LLM_*` unset the AI pipeline runs the
deterministic rule-based fallback (honestly labeled `rule-fallback-v1`), and
weather runs on the labeled simulated feed. Copy `.env.example` → `.env` to
change anything; **never commit a filled `.env`**.

## Layout

```
backend/
  app/
    main.py            # FastAPI app, CORS, /media mount, WS /api/stream
    config.py          # every tunable from env (SAHAYTA_*), sane demo defaults
    database.py        # async engine/session (SQLite default, Postgres-ready)
    models.py          # SQLAlchemy 2.0 models (mirrors docs/data-models.md)
    schemas.py         # Pydantic v2 wire schemas (frozen snake_case)
    auth.py            # X-Device-Id / X-API-Key / X-Admin-Key + rate limits
    ai_client.py       # AI seam: packages/ai-engine if present, else rule fallback
    ws.py              # in-process WS event hub (replay, district filters)
    geo.py / media.py  # haversine; photo store + perceptual dHash
    routers/           # one module per contract section
      sos.py           # intake (multipart+JSON), filters, transitions, verify, assess
      uploads.py       # POST /api/media (photo_id minting)
      shelters.py districts.py volunteers.py tasks.py
      alerts.py admin.py safety.py users.py meta.py
    services/
      matching.py      # volunteer scoring (FROZEN formula)
      risk.py          # district risk formula (documented, deterministic)
      alerts_render.py # 10-language SMS rendering from data/alert-templates/
  alembic/             # migrations (initial schema autogenerated)
  seed.py              # loads data/*.json; honors seed_hints; anchor-checked
  tests/               # pytest suite — 79 tests incl. the full Patna demo scenario
```

## Environment

See the repo-root `.env.example` for every variable. The important ones:

| Var | Default | Meaning |
|---|---|---|
| `SAHAYTA_DATABASE_URL` | `sqlite+aiosqlite:///<repo>/backend/sahayta.db` | DB URL (async driver) |
| `SAHAYTA_ADMIN_KEY` | `demo-admin-key` | admin key — **change in prod** |
| `SAHAYTA_LLM_BASE_URL` / `SAHAYTA_LLM_MODEL` | (unset) | set to enable the real AI engine; unset = rule fallback |
| `SAHAYTA_WEATHER_MODE` | `simulated` | `live` polls Open-Meteo (Wave 3); falls back labeled |
| `SAHAYTA_MEDIA_DIR` | `./backend/media` | uploaded photos (git-ignored) |
